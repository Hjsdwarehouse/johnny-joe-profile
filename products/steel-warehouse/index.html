Steel warehouse buildings

A warehouse is a racking layout with a roof over it. Span, bay spacing and eave height are decided by the storage system and the trucks — this page is about which number moves which part of the frame.

01 / The parameters

What each number decides

Clear spanBetween column centrelines
Bay spacingFrame-to-frame along the length
Eave heightFinished floor to eave
Racking heightDrives the clear height, not the eave

Most warehouse enquiries arrive as a floor area and a rent date. Neither of those tells the drawing office what it needs. A warehouse is really a racking layout with a roof over it, and three numbers follow from the racking before any steel is sized: the clear span between column centrelines, the bay spacing along the building, and the clear height under the haunch.

02 / How it is configured

What gets decided, and in what order

  • Clear span portal frame where the storage plan must stay column-free; a single internal column line where the span would otherwise drive a heavier rafter and a bigger foundation than the layout is worth.
  • Bay spacing set against the purlin and side-rail spans, not copied from another project — widen the bays and the frames get fewer but heavier, narrow them and the frames multiply while each one gets lighter.
  • Eave height taken from the racking plus the lift height plus the clearance the loading equipment needs, then checked against the door and dock arrangement.
  • Roof and wall system chosen for the climate the container is going to: single-skin where the building is unheated storage, insulated where condensation or product temperature matters.
  • Corrosion protection specified per project environment — a coastal site and a dry inland site do not get the same system.
  • Wind loading calculated for the actual location and the applicable code of that country. No default wind speed is applied to every building.
  • Mezzanine and future-extension provision resolved on paper before fabrication, because adding a mezzanine later is a frame decision, not a fit-out decision.

04 / Questions

What buyers ask before the first drawing

When does a warehouse need an internal column line?

When the extra steel in a clear-span rafter, plus the heavier column section and the larger foundation it delivers, costs more than a single line of internal columns would. That crossover moves with span, roof load and the cladding, so it is decided per project rather than from a fixed rule. If the racking layout allows a column line, it is often the cheaper engineering answer rather than a compromise.

What do I need to send to get a warehouse layout started?

Four numbers and one location: the clear span between column centrelines, the building length, the eave height, and the bay spacing you want to work with — plus the site location, because wind, salt and heat change the structure before the span does. If the racking is already specified, send the racking height and the aisle width as well; the clear height follows from those.

Can the warehouse be extended later?

Yes, if the extension is planned before fabrication. Extending along the length means adding bays to an existing frame line, which is straightforward when the frame and the bracing were detailed for it. Extending across the span means changing the frame itself, so it has to be decided at drawing stage, not after the container has shipped.
